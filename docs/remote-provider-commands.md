# Remote provider command capabilities

The remote runner resolves `/compact`, `/approve`, `/recap`, and `/usage` before ordinary model input. Exact command names with whitespace or end-of-input are recognized; filenames such as `/compact.md` are ordinary input. Project commands, installed command templates, discovered skills, and provider-reported executable commands retain ownership of their names.

| Provider | `/compact` | `/recap` | `/usage` | `/approve` |
| --- | --- | --- | --- | --- |
| Claude | Existing native SDK slash-command path; optional native instructions preserved | Native `--resume --fork-session` side query, no tools or persistence; one line, at most 400 characters | Classified session facts and native rate-limit observations when supplied | The terminal has a recently blocked action review, but the headless SDK exposes no equivalent historical-action approval handle |
| DSH | Public native command registry through the HAPI ACP adapter extension; native argument grammar is preserved | Not provided by the installed native registry | Latest reported usage/context facts | Not provided by the installed native registry |
| AGY | No safe headless compaction operation is integrated | No isolated recap operation is integrated | Latest usage reported in streamed step/result envelopes | No equivalent headless retry operation is integrated |
| Pi | Existing native compact RPC, including custom instructions | Not integrated; discovered extension commands keep precedence | Live native `get_session_stats` query, with reported session totals; `/session` also remains available | Not integrated; discovered extension commands keep precedence |
| OpenCode | Existing native session summarization API | Not integrated | Latest reported session usage | Not integrated |
| Cursor / Grok | Sent through the existing ACP command path only when the current ACP session advertises it | Only a provider-reported executable command can own this name | An advertised native command takes precedence; otherwise latest reported session usage | Only a provider-reported executable command can own this name; no permission-policy alias is invented |
| Copilot / Kimi | No new compaction operation is claimed | Not integrated | Latest reported session usage | Not integrated |

An unavailable built-in receives a local explanation and is not sent to the model as a chat prompt. `/approve` does not toggle a permission mode or approve a different pending request. A user-defined command with that name retains its existing provider behavior.

The local `/usage` report groups meaningful fields into tokens, context capacity, cost/duration, activity, and account limits. It does not print response JSON or raw wire field names. A provider's live read-only usage query is preferred when available; otherwise the source is explicitly the last report received by this running HAPI process. It is not a reconstructed session total. Before a report arrives it says that no usage is available. ACP context-only updates do not become fictitious zero-token bills. Claude synthetic API errors and subagent messages do not replace the main conversation snapshot.

Remaining context space is calculated only from a reported occupancy and measured capacity, and is labeled separately from account allowance. Guessed context denominators are excluded. Native Claude `rate_limit_event` utilization and reset facts, when present, appear as their own account window with used/remaining percentages; an expired window is not presented as current remaining quota. When a provider does not report account limits or credits, the report explicitly says so. It does not fetch private account endpoints or infer quota from token counts.

Claude `/recap` requires an existing native conversation and accepts no arguments or attachments. It now follows the native human-facing semantics: a single short line about what just happened and what is next, capped at 400 characters. The shared prompt and Unicode-safe normalizer are used by Claude and Codex. The independent query reads a native fork, disables built-in tools and MCP servers, disables hooks and slash expansion, and uses `--no-session-persistence`. Its temporary native session ID is not adopted by HAPI. A timeout or session shutdown cancels the query; the main conversation's thinking state, model preference, and permission settings are not changed. This on-demand operation uses a model request and may incur provider usage.

The [official Session recap documentation](https://code.claude.com/docs/en/interactive-mode#session-recap) distinguishes manual recap from the terminal's automatic return summary. Native automatic recaps require at least three turns, an unfocused terminal, and at least three minutes since a completed turn; they do not occur consecutively or in non-interactive mode. HAPI already forwards native `away_summary` records from terminal sessions. This change adds no background recap generation, timer, or automatic model request.

The [official auto-mode denial review](https://code.claude.com/docs/en/auto-mode-config#review-denials) is a native terminal operation on a specific blocked action. The [PermissionDenied hook](https://code.claude.com/docs/en/hooks#permissiondenied) is not a manual approval API for an earlier denial: its retry output tells the model it may retry during the current denial flow and does not reverse the denial. HAPI's current SDK control surface approves a currently pending request by request ID; it has no public historical-denial retry token. DSH's `permission` command changes presets, and standard ACP permission responses decide live requests. Neither is substituted for the one-time rejected-action semantics of `/approve`.

DSH command execution uses public `ctx.commands.list` / `ctx.commands.execute`, exact owned Agent identity, an idle session, and the original command's grammar. The ACP readable transport remains available during execution so `session/cancel` can abort the command. The default installed DSH registry exposes `compact`, `feedback`, `goal`, `permission`, and `plan`. A custom ACP server that does not advertise the HAPI command extension receives an explicit unsupported result for `/compact`. Attachments are not admitted for this adapter's native `/compact` path.

Verification used the installed DSH 0.2.0-rc.2 with a deterministic local LLM adapter: native `/compact` executed with its own command ID and returned “No compactable history yet.” without another `session/prompt`. The installed Claude CLI was tested against a local deterministic HTTP provider: the recap used a different session ID, offered no tools, and left every persisted source-conversation JSONL file and its hash unchanged. No external model or user conversation was used in those probes. Cursor/Grok executable command availability is determined from the running ACP session; their binaries were not exercised in the local probes.
